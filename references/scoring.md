# B 站适配度评分规则

## 一、五维软指标（LLM 打分，0-10 分）

| 维度 | key | 定义 | 打分锚点 |
|------|-----|------|----------|
| 视觉冲击 | `visual` | 食欲感/奇观感/画面质感。画面能否让人"哇"出来 | 10=拉丝/爆炒/巨型食物/罕见奇观；4=普通家常画面；1=纯坐聊 |
| 猎奇新鲜感 | `novelty` | 中国观众没见过、超出常识的程度 | 10=全新未知领域（罕见国家街头/奇葩工艺）；6=见过但陌生（印度/中东/非洲）；3=熟悉的欧美日常；1=国内也常见 |
| 文化接近性 | `cultural` | 与中国观众的饮食/文化共鸣。越接近越亲切 | 10=中日韩/华人题材；7=东南亚/印度（亚洲熟悉香料系）；4=拉美/中东；2=纯欧美冷门菜系 |
| 叙事适配 | `narrative` | 画面驱动 vs 口播驱动的比例，及叙事密度 | 10=画面自解释、弱口播、剪辑快节奏；6=口播密集但故事强；3=依赖英语梗/字幕才能看懂；1=纯访谈 |
| 爆点强度 | `explosion` | 标题党潜力：冲突/反差/悬念/争议，B 站标题能不能炸 | 10=天然爆点（最贵/最便宜/翻车/挑战/老板有故事）；5=平稳好看；1=平淡纪录 |

## 二、总评公式

```
total = 0.22*visual + 0.18*novelty + 0.15*cultural + 0.15*narrative + 0.30*explosion
```

再加两个硬分微调（脚本算）：
- **热度增速**：view_count / (days_old + 1)。周内 >100 万/天 为顶级热点，排名前 20% 加 0.3 分
- **时长适配**：8–25 分钟最适配 B 站（+0.2）；<5 分钟偏短（0）；>40 分钟偏长（-0.1）

## 三、人群映射（每视频标 1–2 个主适配人群）

| 人群 | 画像 | 选题偏好 | 时长 | 内容形态 |
|------|------|----------|------|----------|
| **M. 移动端碎片** | 18–30，通勤/睡前刷 | 街头探店/亚洲美食/工厂揭秘 | ≤15min | 画面驱动、强冲击、弱口播依赖 |
| **P. PC 端深度** | 25–40，大屏+全屏专注 | 历史文化/餐厅主厨/深度调查 | 15–35min | 叙事强、知识密度高，可接受字幕 |
| **T1. 一二线精致** | 北上广，消费力强 | 米其林/主厨/Omakase/精致探店 | 不限 | 精致感、专业感、生活方式向 |
| **T2. 二线性价比** | 量大实惠审美，猎奇挑战 | 便宜挑战/巨量食物/街头硬核 | ≤20min | 量大、便宜、猎奇、"¥"叙事 |
| **K. 25–40 知识向** | 主力用户，爱涨知识 | 工厂揭秘/食物历史/产业调查 | 10–30min | "原来如此"型知识满足 |

**类型 → 人群速查**：
- 街头探店(1) → M / T2
- 餐厅厨师(2) → T1 / P
- 历史文化(3) → P / K
- 食材工厂(4) → K / M
- 亚洲美食(5) → M / T2 / T1（日韩偏 T1，印东南亚偏 T2）
- Vlog融合(6) → M（视具体内容）

## 四、打分输出格式（scores.json）

LLM 读 `videos_raw.json` 后写 `scores.json`：

```json
[
  {
    "video_id": "xxxx",
    "visual": 9, "novelty": 8, "cultural": 7, "narrative": 9, "explosion": 8,
    "audiences": ["M", "T2"],
    "reason": "一句话：这个选题的爆点是什么，为什么 B 站用户会点",
    "bili_title_hint": "如果二创，标题可以往哪个方向打"
  }
]
```

打分依据：标题 + 频道背景（references 里 6 类频道的已知风格）+ 简介。信息不足时保守打 5 分，不臆造。
